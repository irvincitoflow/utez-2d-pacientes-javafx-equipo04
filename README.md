# utez-2d-pacientes-javafx-equipo04
Sistema de Gestión de Información Clínica: "Directorio de Pacientes"

Asignatura: Programación Estructurada

Descripción General

Esta aplicación de esc[]()ritorio, desarrollada en JavaFX, tiene como objetivo automatizar el registro y control de pacientes para un consultorio médico. El sistema implementa un ciclo de vida de datos completo (CRUD) y garantiza la integridad de la información mediante validaciones lógicas y persistencia física en archivos planos.
